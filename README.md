# JWT Auth Frontend

This project is a frontend application for JWT-based authentication. It allows users to register, log in, and access protected resources using JSON Web Tokens.

## Features

- User registration and login
- JWT token management (storage, refresh, logout)
- Protected routes and components
- Responsive UI

## Technologies Used

- React
- Axios
- React Router

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Start the development server: `npm start`

## Configuration

Update API endpoints and JWT settings in the configuration files as needed.
